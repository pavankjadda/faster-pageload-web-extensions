Faster Pageload is installed

Make sure Firefox is allowed to prefetch pages

Link prefetching is enabled in Firefox by default, but privacy-hardened setups (for example arkenfox or LibreWolf) turn it off. If pages don't load faster:

  1. Open about:config
  2. Search for network.prefetch-next and make sure it is true

Faster Pageload preloads links on the same site when you hover over them. Lazy loading of images and preloading of every visible link can be turned on in the add-on options.
